# LogiLink 화면 개선 내역 (2026-11-12)

## 1. 목적

이 문서는 PDA 상차담당이 메뉴를 오가지 않고 한 화면에서 상차할 차량, 상차 중 차량, 상차완료 차량을 모두 볼 수 있게 바꾼 내용을 기록합니다. 상차 작업 화면을 정의서 v1.5의 상차 재개 규칙(D20)에 맞춘 내용과, 같은 날 웹 대시보드의 가독성을 개선한 내용도 함께 남깁니다.

업무 규칙 변경은 **두 가지(무지시 상차 재개 불가 3-1, 출차 신설과 재개 기간 "출차 전" 3-3)**입니다. 그 밖의 정의서 v1.5 ④ 상차등록, C5·C6, D10~D13, D20 규칙은 그대로이며, 나머지 변경은 **화면 구성·문구·조회 방식**에 한정됩니다.

## 2. PDA 상차등록 + 상차내역 통합

### 2-1. 변경 요약

| 구분 | 변경 전 (2026-11-05 PDA 메뉴 확정) | 변경 후 |
|---|---|---|
| 상차담당 메뉴 | 대시보드 · 상차등록 · 상차내역 | 대시보드 · 상차등록 |
| 상차등록 화면 | 오늘(과 출고일 지난) 상차할 차량, 상차 중 차량 | 상차할 차량, 상차 중 차량, **상차완료 차량**을 한 화면에서 조회 |
| 조회 조건 | 없음 (항상 오늘) | 검정 영역 스캔칸 아래 한 줄에 **날짜 칸**(오늘 / MM-DD, 누르면 달력)과 **보기 버튼**(전체·상차할·상차 중·완료, 건수 표시) 추가 |
| 목록 형식 | 카드 | 카드 유지 (표 형식은 PDA 너비·터치 영역 문제로 채택하지 않음) |
| 상차내역 화면 | 날짜별 상차완료 차량 | 상차등록의 "상차완료" 보기로 흡수. 예전 주소(`/pda/loads`)는 상차등록 "상차완료" 보기로 자동 이동 |

검정 영역의 **상차지시서 스캔 / LO- 번호 입력칸은 그대로 유지**했습니다. 검정 영역 맨 위의 요약 줄("오늘 상차할 N대 · 상차 중 · 완료")은 삭제했습니다.

### 2-2. 보기 버튼 줄

처음에는 드롭다운으로 만들었으나, 펼치기 전에는 어떤 항목인지 한눈에 보이지 않아 **건수가 붙은 버튼 4개를 한 줄로 두는 방식**으로 바꿨습니다. 이후 검정 영역이 세 줄로 길어져, 날짜를 버튼 줄 맨 앞의 작은 칸으로 합쳐 **스캔칸 + 날짜·보기 한 줄**의 두 줄 구성으로 줄였습니다(A안). 선택된 버튼만 흰색으로 표시됩니다. PDA 너비(360px)에 한 줄로 들어가도록 버튼 이름은 짧게 씁니다.

| 버튼 (건수) | 보이는 목록 |
|---|---|
| **전체 N (기본값)** | 상차 중인 차량(있을 때만) → 상차할 차량 → 상차완료. 건수는 세 목록의 합 |
| 상차할 N | 상차 전 지시서 차량만 |
| 상차 중 N | 상차를 시작했고 아직 상차완료 전인 차량만 |
| 완료 N | 조회 날짜에 상차완료한 차량만 (상차확인서 번호·바코드 다시 보기) |

### 2-3. 날짜 규칙

상태마다 기준이 되는 날짜가 다르기 때문에, 날짜 하나로 거를 때 아래 규칙을 따릅니다.

| 목록 | 날짜 기준 | 규칙 |
|---|---|---|
| 상차할 차량 | ASN 출고일 | 오늘을 고르면 **출고일이 지난 상차 전 차량도 함께** 보입니다. 지난 날짜를 고르면 출고일이 그 날짜인 상차 전 차량만 보입니다. |
| 상차 중 | 날짜 무관 | **어떤 날짜를 골라도 항상** 보입니다. 날을 넘긴 상차 중 차량이 목록에서 빠지지 않게 하기 위해서입니다. |
| 상차완료 | 상차일 | 고른 날짜에 상차완료한 차량만 보입니다. |

조회 날짜는 오늘까지만 고를 수 있습니다. 날짜 칸은 오늘이면 "오늘", 지난 날짜면 "MM-DD"로 표시하고, 지난 날짜를 보는 동안에는 칸을 **노란색**으로 바꿔 오늘이 아님을 알립니다. 날짜 칸을 누르면 달력이 열리고, 달력에서 다른 날짜나 오늘을 고를 수 있습니다.

### 2-4. 상차 중·출고일 지남 표시

| 대상 | 표시 |
|---|---|
| 상차 중인 차량 | 카드 바탕 **연한 주황**(PDA 대시보드 "상차 중" 칸과 같은 색) + 카드 왼쪽 주황 띠. 별도 알약은 두지 않음 |
| 상차완료 차량 | 카드 바탕 **연한 연두**(PDA 대시보드 "상차완료" 칸 계열, 상차 중 카드와 같은 연하기) + 카드 왼쪽 초록 띠. [상차완료]·[차이 있음] 알약은 유지 |
| 날을 넘긴 상차 중 차량 | 카드 아래 "MM-DD 시작 · 아직 상차완료 전" 안내 |
| 출고일이 지난 상차할 차량 | **[출고일 지남]** 알약(빨강) + "출고일 YYYY-MM-DD" 안내 |
| 출고일이 지난 상차 중 차량 | 연한 주황 카드 + [출고일 지남] 알약 |

상차 중 카드의 상차 구분(지시 상차·무지시 상차)은 알약 대신 카드 둘째 줄 글자로 옮겼습니다. 알약은 상태 표시에만 씁니다.

### 2-5. 사용 편의 처리

- **스캔 커서 복귀:** 날짜나 보기를 바꾸면 커서가 스캔칸으로 자동으로 돌아갑니다. 바코드가 날짜칸에 입력되지 않게 하기 위해서입니다.
- **돌아가기 유지:** 목록에서 차량을 눌러 상차 작업·상차확인서로 들어간 뒤 ← 를 누르면, 들어가기 전의 날짜·보기 그대로 돌아옵니다.
- **PDA 대시보드 연결:** 대시보드의 상차할 차량·상차 중·상차완료·차이 있음 칸과 "최근 상차완료 전체 보기"는 상차등록의 해당 보기로 연결됩니다.

- **PDA 대시보드 칸:** 상차할 차량(트럭)·상차 중(상자)·상차완료(체크)·차이 있음(경고) 칸에 아이콘을 넣고 높이를 조금 높였습니다. 아이콘은 칸 왼쪽 위, 이름은 아이콘 옆, 숫자는 칸 오른쪽에 둡니다. 칸 이름은 "상차할" → "상차할 차량", "작업 중" → "상차 중"으로 바꿨고, 상차등록 화면의 보기·알약·목록 제목도 "상차 중"으로 맞췄습니다.
- **카드 진행 단계:** 목록 카드 안의 상차 시작 · 상차 중 · 상차완료 표시는 체크를 빼고 작은 점으로 줄였습니다. 지난 단계는 검정 점, 남은 단계는 회색 점입니다. 같은 부품을 쓰는 입고검수 목록 카드도 함께 바뀝니다.

## 3. PDA 상차 작업 화면 — 상차 재개 규칙(v1.5 D20) 반영

정의서 v1.5에서 "상차완료 후에도 검수 시작 전까지 사유와 함께 재개해 더 실을 수 있다(확인서 번호 유지 + 차수)"로 바꿨지만, 상차 작업 화면에는 이전 규칙의 문구와 흐름이 남아 있어 아래와 같이 맞췄습니다.

### 3-1. 규칙 변경 — 무지시 상차는 재개하지 않음, 지시 상차는 출차 전까지

| 구분 | 재개 가능 여부 |
|---|---|
| 지시 상차 | **출차 전까지 가능.** 상차완료 후 **출차(3-3) 전**이고 입고검수(진행·확정)가 시작되기 전이면 재개할 수 있습니다. 출차하지 않았으면 같은 업무일 안에서만 가능합니다(업무일이 지나면 자동 출차). 자기 ASN 품목은 날짜와 무관하게 실을 수 있고, 지시 외 품목은 그날 ASN에 있는 품목만 경고 후 실을 수 있습니다. |
| 무지시 상차 | **불가 (2026-11-12 Sol 결정).** 상차완료 후에는 재개할 수 없고, 더 실을 물량은 새 무지시 상차로 등록합니다. 다음 날 재개 시 "오늘 ASN 품목" 기준이 바뀌어 이미 실은 품목도 막히는 문제를 함께 없앱니다. |

서버에서도 무지시 상차 재개 요청은 거부합니다.

### 3-2. 화면 문구·흐름 수정

| # | 위치 | 변경 전 | 변경 후 |
|---|---|---|---|
| 1 | 상차완료 확인 창 안내 | "완료하면 더 입력할 수 없습니다." | 지시: "완료하면 상차확인서가 발행됩니다. 출차 전까지는 [상차 재개]로 더 실을 수 있습니다." / 무지시: "…무지시 상차는 완료 후 재개할 수 없습니다." |
| 2 | 재개 후 다시 완료할 때 확인 창 | 처음 완료와 같은 문구 | "완료하면 확인서가 N차로 바뀝니다. 이전에 인쇄한 확인서는 웹에서 다시 인쇄하세요." 추가 |
| 3 | 완료 화면 제목 | 항상 "상차확인서를 발행했습니다." | 재완료면 "상차확인서 N차를 발행했습니다." + "이전 차수 확인서는 쓰지 마세요…" |
| 4 | 완료 화면 [상차 재개] | 버튼만 | 버튼 아래 "빠뜨린 품목이 있으면 출차 전까지 재개해서 더 실을 수 있습니다." 무지시는 버튼 대신 "무지시 상차는 재개할 수 없습니다…" |
| 5 | 재개 창 안내 | "…인쇄한 확인서는 다시 인쇄해야 합니다." | "다시 상차완료하면 확인서가 N차로 바뀝니다(인쇄했다면 웹에서 다시 인쇄). 지시 품목과 오늘 ASN에 있는 품목만 실을 수 있고, ASN에 없는 새 품목은 실을 수 없습니다." |
| 6 | 재개한 차량의 작업 화면 머리 | "상차 중 · 09:10 시작 · 센터" | "상차 중 · 14:20 재개(사유) · 센터" |
| 7 | 상차등록 목록 카드 | 재개 차량 구분 없음 | 상차 중 카드에 "재개 N차" 표시 |
| 8 | 목록에서 지난 확인서를 열 때 | "상차확인서를 발행했습니다." + 체크 원 | "상차확인서(· N차)" 조회 제목, 체크 원 없음. 방금 완료했을 때만 "발행했습니다". 작업 중 다른 작업자가 완료하면 "다른 작업자가 상차완료했습니다." |
| 9 | 완료 화면을 열어 둔 채 검수가 시작된 경우 | [상차 재개] 버튼이 그대로 남음 | 화면에 다시 돌아오거나 [상차 재개]를 누를 때 최신 상태를 읽어, 검수가 시작됐으면 안내 문구로 바뀜 |

### 3-3. 출차 신설 — 재개 가능 기간을 "출차 전"으로

일반적인 물류센터는 적재 → 문 닫기·봉인 → 서류 인계 → **출하 확정(출차)** 순서로 진행하고, 출하 확정 뒤에는 기록을 다시 열지 않습니다. 차가 떠난 뒤에는 실물을 더 실을 수 없기 때문입니다. 이에 맞춰 상차 재개 기간을 "입고검수 시작 전"에서 **"출차 전"**으로 좁히고, 출차를 기록하는 단계를 추가했습니다.

```
상차할 차량 → 상차 중 → 상차완료(출차 전) → 출차
                        ↑ 이 구간에서만 [상차 재개] (지시 상차만)
                        └ [출차]를 누르지 않으면 상차완료한 업무일이 지나면 자동 출차
```

| 항목 | 내용 |
|---|---|
| 누가·어디서 | PDA 상차담당이 **상차완료 화면의 [출차]** 버튼을 누릅니다. 메뉴는 새로 만들지 않습니다. 확인 창("출차하면 상차를 다시 열 수 없습니다…")을 거칩니다. |
| 목록 카드 | [출차] 버튼은 두지 않습니다(되돌릴 수 없는 동작이라 잘못 누름 방지). 상차완료 카드에 **[출차 전]** 알약을 붙이고 목록 위쪽에 모읍니다. 출차한 카드는 "완료 14:20 · 출차 14:30"으로 표시합니다. |
| 출차 후 | 상차 재개 불가, 출차 취소 없음. 상태는 상차완료 그대로이며 출차 시각·처리자만 남깁니다. 지시·무지시 모두 출차합니다. |
| 자동 출차 | [출차]를 누르지 않았으면 **상차완료한 업무일(도착 센터의 업무일 시작 시각 기준)이 지나면** 출차로 봅니다. DB에 쓰지 않고 볼 때마다 판단하며, 시각은 그 업무일이 끝난 시각으로 "자동 출차(업무일 마감)"라고 표시합니다. |
| 출차 시각 표시 | PDA 완료 화면(출차 줄)·상차등록 목록 카드, 웹 ASN 상세·무지시 상차 상세의 상차 실적 카드(출차 줄), ASN·상차 현황 목록(상차완료 행의 상태 아래 "출차 전/출차 시각/자동 출차"), A4 상차확인서(출차 칸, 출차 전 인쇄면 "출차 전"). ASN 처리 이력에 "출차"가 남습니다. |
| DB | `tb_load_h`에 출차 시각(depart_dt)·처리자(departed_by·depart_user_id) 추가, 상차 이력·ASN 이력에 출차 행위 추가(마이그레이션 `20261112000000_load_depart`). **로컬 시험 DB에만 적용** — 운영·시연 DB는 승인 후 반영합니다. |

## 4. PDA 입고검수 — 상차등록 PDA와 같은 UI로

입고검수 PDA의 대시보드·첫 화면·검수 화면을 상차등록 PDA와 같은 모양으로 맞췄습니다. 검수 규칙(정의서 ⑥·C7·D15·D22)은 바꾸지 않았고, 바꿀 필요가 없는 부분(품목 줄의 0 확인·사유·사진·소비기한·로트, 자동 배분 표시)은 그대로 두었습니다.

### 4-1. 대시보드

| 칸 | 색 | 아이콘 | 누르면 |
|---|---|---|---|
| 검수 대기 | 기본(회색) | 트럭 | 입고검수 "대기" 보기 |
| 검수 중 | 주황 | 스캔 | "검수 중" 보기 |
| 검수확정 | 초록 | 체크 | "완료" 보기 |
| 이상 있음 | 붉은 | 경고 | "완료" 보기 |

아이콘·이름은 칸 왼쪽 위, 숫자는 오른쪽 아래(상차담당 대시보드와 같은 배치)입니다.

### 4-2. 입고검수 첫 화면 — 검수 내역 메뉴 통합

| 구분 | 변경 전 | 변경 후 |
|---|---|---|
| 입고검수자 메뉴 | 대시보드 · 입고검수 · 검수 내역 | 대시보드 · 입고검수 (예전 검수 내역 주소는 "완료" 보기로 이동) |
| 검정 영역 | 위 요약 줄(검수 대기 N대 · 검수 중 · 오늘 확정) + 스캔칸 | 스캔칸 + **날짜칩·보기 버튼 한 줄**(전체·대기·검수 중·완료, 건수) — 상차등록과 같은 조각 |
| 날짜 규칙 | (검수 내역만 날짜) | 대기·검수 중은 날짜와 상관없이 항상(남은 일), 완료는 확정한 날짜. 오늘 전에 상차완료한 대기 차량은 "MM-DD 상차완료 · 아직 검수 전" 안내 |
| 카드 | 회색 카드 + [검수중]·[이상 없음] 알약 | 대기 회색(상차 구분 알약 유지) · 검수 중 **연한 주황 + 주황 띠** · 확정 **연한 연두 + 초록 띠**. 확정 카드 알약은 [이상 N건]만 |

### 4-3. 검수 화면 (작업·결과)

| 항목 | 변경 전 | 변경 후 (상차 작업과 같게) |
|---|---|---|
| 머리 | [검수중] 알약 + 긴 상태 줄(시작·마지막 입력·화주사·구분·상차확인서) | [지시 상차/무지시 상차] 알약 + "검수 중 · 09:10 시작 · 화주사" |
| 상차 정보 | 머리에 섞여 있음 | 접힌 **검수 정보**(상차확인서·지시서·상차완료·기사·검수자) |
| 입력 결과 알림 | 토스트(잠깐 뜨는 글자) | 방금 입력·정정·취소한 **품목 줄로 이동해 잠깐 강조** |
| 수량 경고 | 스캔 칸 안 경고 상자 | 아래에서 올라오는 확인 창 [수량 고치기] / [그대로 입력] |
| 내 입력 취소 | 브라우저 확인창 | 아래에서 올라오는 확인 창 [그만두기] / [입력 취소] |
| 검수 확정 확인 | 별도 화면(검수자 목록 + 품목 목록 + 아래 버튼) | 아래에서 올라오는 확인 창 — 입력 n/m품목, 확인 필요 품목과 이유, 검수자, 미입력 품목이면 창 안에서 [돌아가서 스캔] / [남은 품목 전부 0 처리] |
| 아래 띠 | 위에 "확인 필요 N개" 글자 + [검수 확정] | 한 줄: 확인 필요 N(있을 때만) + [검수 확정]. 미입력 개수는 지금처럼 띠에 표시하지 않음(2026-11-06 결정) |
| 확정 화면 | 항상 "검수를 확정했습니다." + 체크 원 | 방금 확정했을 때만 체크 원·"확정했습니다", 목록에서 열면 "검수 결과", 다른 검수자가 확정하면 그 안내 |
| ← 돌아가기 | 검수 내역에서 열면 검수 내역으로 | 들어온 입고검수 목록(날짜·보기) 그대로 |

훼손 사진을 지울 때의 확인은 브라우저 확인창 그대로 두었습니다(필요하면 확인 창으로 바꿀 수 있습니다).

### 4-4. 동시 검수 중 차이 사유 요구 개선

여러 검수자가 한 품목을 나눠 세는 경우(예: 상차 100 BOX 중 검수자 1이 40 BOX 입력, 검수자 2는 세는 중), 40 BOX를 넣는 순간 화면이 "확인 필요 · 차이 사유를 고르세요"로 바뀌어 아직 다 세지 않은 품목에 사유를 요구했습니다. 서버는 원래 확정 때만 사유를 검사하므로, **화면이 묻는 시점을 확정 때로 옮겼습니다**(상차 작업의 차이 사유와 같은 흐름). 검수 규칙은 바뀌지 않습니다.

| 시점 | 변경 전 | 변경 후 |
|---|---|---|
| 세는 동안 | 상차 수량과 다르면 "확인 필요", 품목 줄 자동 펼침, 사유 요구, 아래 띠 숫자 증가 | "40 BOX / 100 BOX" + **진행 막대**(부족 주황·일치 초록·초과 빨강)와 상태 글자만. 사유는 묻지 않음(원하면 줄을 펼쳐 미리 골라 둘 수 있음) |
| 품목별 입력자 | 검수자 이름만 | 검수자가 2명 이상이면 **"홍길동 40 BOX · 김민수 —"**처럼 사람별 수량(안 넣은 사람은 —) |
| 바로 손볼 것 | 사유·상세·훼손 사진 | **훼손 사진만**(발견한 사람이 그 자리에서). 아래 띠 "확인 필요"도 사진 없는 훼손 품목만 셉니다 |
| 검수 확정 확인 창 | 확인 필요 품목 이름만 나열 | **차이 품목마다 수량(센 / 상차)·상태를 보여 주고 그 자리에서 사유 선택**(기타는 상세 입력). 사유가 비었거나 사진이 없으면 [검수 확정]을 막음. "다른 검수자가 아직 세고 있지 않은지 확인하세요" 안내 유지 |

**실물 없음(0 확인) 품목:** 사유는 서버가 "미도착"으로 자동 지정하므로 품목 줄과 확정 확인 창 모두 사유 드롭다운을 두지 않습니다. 받을 실물이 없으므로 소비기한·로트 입력칸도 숨깁니다. 해당 품목의 품목명·수량 글자는 품목코드와 같은 회색으로 표시하고, "0 확인" 상태 글자는 지금 색 그대로 둡니다.
