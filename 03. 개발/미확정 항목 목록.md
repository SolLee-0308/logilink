# 미확정 항목 목록

> 정의서(`01. 프로세스/01-입고 업무프로세스 정의서_v1.4.md`)에 값이나 규칙이 없어 개발에서 임시로 정했거나, Sol이 "나중에 정하자"고 한 항목입니다. 확정되면 이 목록에서 지우고 반영합니다.

## 1. 보류 (나중에 정하기로 한 것)

| No | 항목 | 현재 상태 · 메모 |
|---|---|---|
| H1 | 차량 기준정보 | 정의서 ③은 "차량을 선택해 분배"하지만, 한 차량이 여러 화주사 품목을 싣거나 오전·오후에 다른 화주사를 실을 수 있어 더 검토하기로 함 (2026-11-02 Sol). 차량을 화주사에 묶지 않는 구조(공용 차량 + 운행·배차 단위로 화주사 연결)가 후보. ASN 단계 전에 결정 필요 |
| H2 | 단말(PDA) 관리 | 상차 입력 행에 device_id만 남김. 단말 목록·분실 단말 차단은 보류 (2026-11-02 Sol) |

## 2. 임시안 (값·규칙을 임시로 정한 것)

| No | 항목 | 임시안 | 바꾸는 곳 |
|---|---|---|---|
| U1 | 사유 코드 값 — 검수 차이·반송 | 수량 부족, 수량 초과, 훼손·오염(반송), 품목 불일치(반송), 미도착, 기타 | 기준정보 › 사유 코드 (`RCV_DIFF`) |
| U2 | 사유 코드 값 — 잔량 종결 | 미도착, 화주사 요청, 기타 | 기준정보 › 사유 코드 (`REMAIN_CLOSE`) |
| U3 | 사유 코드 값 — 입고예정 반려 | 승인 대기 시안의 임시값 6개 | 기준정보 › 사유 코드 (`PLAN_REJECT`) |
| U4 | 사유 코드 값 — 취소 | 화주사 입고 취소 요청, 중복 등록, 입고 일정 변경, 기한경과(일마감 자동), 기타 | 기준정보 › 사유 코드 (`CANCEL`) |
| U5 | 사유 코드 값 — 품목 등록 반려 | 기존 품목과 중복, 바코드 오류·중복, 단위 확인 필요, 품목 정보 부족, 기타 | 기준정보 › 사유 코드 (`ITEM_REQ_REJECT`) |

| U7 | 품목 단위 | EA / BOX / PLT 3종 고정. 기준 단위 1개 + 나머지는 기준 단위 환산 수량(정수) | `src/domain/master.ts`, DB enum `ItemUnit` |
| U8 | 바코드 형식·범위 | 숫자 8~14자리. 단위별로 여러 개, 같은 화주사 안에서 하나의 품목·단위만 가리킴. 품목당 대표 바코드 1개 | `src/domain/master.ts` |
| U9 | 품목 별칭 비교 방식 | 공백 제거 + 소문자로 같으면 같은 별칭. 같은 화주사 안에서 유일 | `normalizeAlias()` |
| U10 | 유통기한·로트 관리 | 품목별 "유통기한 관리", "로트 관리" 2개 표시. 관리 품목은 입고예정 입력 필수, 검수 시 실물과 다르면 현장 입력 (Sol 결정). 입고 가능 잔여 유통기한 기준(예: 70%)은 아직 없음 | 기준정보 › 품목 |

| U12 | 이력 테이블 | 정의서의 테이블별 `_HIS` 대신 기준정보는 공통 변경 이력(`tb_change_log`) 한 테이블 | `prisma/schema.prisma` |
| U13 | 미종결 알림 기준 경과일 (O2) | 3일, 1~30일 범위 | 기준정보 › 운영 설정 |
