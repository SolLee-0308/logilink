# 개발 착수~1단계 대화 요약

## 1. 요약

2026-10-29 하루 동안 로지링크 입고 모듈 개발 환경을 구성하고, **0단계(기본 설정·로그인·기준정보)**와 **1단계(입고예정 등록·승인)**를 완료했다. 그 과정에서 Sol이 추가·개정한 설계 문서(04 기준정보·운영정책, 03 상태 전이, IA 화면 목록)를 순서대로 코드에 반영했다. 다음 작업은 입고예정 화면 검수이며, 그 뒤 2단계(ASN·상차)로 넘어간다.

## 2. 개발 기본 방향 (착수 시 합의)

| 항목 | 결정 |
| --- | --- |
| 범위 | 버전 1 전체, 0~4단계로 나눠 단계마다 Sol 확인 |
| 기술 스택 | Next.js 16 · TypeScript · Prisma 7 · PostgreSQL(Supabase) · Auth.js |
| PDA | 별도 앱 없이 모바일 웹 화면 |
| 권한 | 실제 로그인 구현 |
| 미확정 정책 | 임시안으로 구현하고 `미확정` 표시 (`03. 개발/미확정 항목 목록.md`) |
| 개발 폴더 | `03. 개발` |

## 3. 진행 경과

| 순서 | 내용 | 결과 |
| ---: | --- | --- |
| 1 | 프로젝트 생성, DB 스키마, 로그인·권한, 기준정보 화면 | 0단계 1차 완료 |
| 2 | Supabase 연결(접속 주소 오류 수정), 공개 API 차단(RLS) | 모든 테이블 공개 API 권한 0건 |

| 4 | "샘플" 문구 제거, 조회 영역 우선 배치(혼합형) | 기준정보 화면 개편 |
| 5 | 리마인더 개정 반영(승인대기 수정 시 작성중 복귀 등), 화주사 상차 담당 역할 신설 | 상태 규칙 수정 |
| 6 | 04 기준정보·운영정책 문서 반영 | 3PL 조직, 화주사–센터 운영모드, 정책 우선순위, 바코드 기간 유일, 역할 할당, 승인 위임 |
| 7 | 1단계 입고예정·승인 개발 | 직접 입력·엑셀·AI 판독, 제출본·승인본, 부분 승인 |
| 8 | 문서 03(상태 전이)·IA 문서 반영 | 입고예정 워크스페이스, 업무 홈 작업함, 운영모드별 메뉴 |

## 4. Sol의 주요 결정

| 구분 | 결정 내용 |
| --- | --- |
| 화면 테마 | 딥 네이비, CI 색상 `#D99694`, 좌측 메뉴 접기·펼치기 |
| 기준정보 화면 | 상단 조회 조건 → 목록 → 오른쪽 패널에서 등록·수정 |
| 업무 화면 | **워크스페이스**: 왼쪽 목록 + 오른쪽 상세·작업·이력 (IA 문서 기준, 기존 혼합형에서 변경) |
| 상차 역할 | `화주사 상차 담당` 신설, 기존 화주사 담당자는 `화주사 출하 담당` |
| 역할 추가 | 04·03 문서의 세부 역할은 새로 만들지 않고 기존 6개 역할에 연결 |
| 운영 설정 권한 | 화주사–센터 운영 설정은 3PL 관리자만 변경 |
| 부분 승인 | 허용 (줄이면 사유 필수, 0이면 이번 승인에서 제외) |
| 승인 후 변경 | 승인완료 → 작성중(수정) → 재승인, 재승인 전까지 직전 승인본 유효 |
| 입고예정 취소 | 승인대기 + 제출 이력 있는 작성중·보완필요는 취소, 미제출 작성중은 삭제 |
| AI 판독 | Claude API로 구현, **API 키는 4단계 완료 후 발급** |
