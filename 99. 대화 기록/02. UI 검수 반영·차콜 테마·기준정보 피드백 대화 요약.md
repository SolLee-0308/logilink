# UI 검수 반영·차콜 테마·기준정보 피드백 대화 요약

## 1. 요약

2026-10-29 저녁에 1단계 UI 검수 결과(IA 3-2·3-5·3-6, 04 문서 13장 개정)를 코드에 반영했다. 입고예정 화면을 워크스페이스에서 **목록 → 전체 상세** 구조로 바꾸고, 테마를 **뉴트럴 차콜**로 바꿨다. 이어서 기준정보 구성을 04 문서와 대조한 피드백을 `04. 피드백` 폴더에 작성했고, 조회 영역 배경색을 쿨 그레이로 변경했다. 다음 작업은 피드백 문서의 결정 사항(FB-MD-01~05) 확정 후 기준정보를 보강하는 것이다.

## 2. 진행 경과

| 순서 | 내용 | 결과 |
| ---: | --- | --- |
| 1 | 이전 대화 요약 숙지 | 개발 기본 방향·1단계 현황 확인 |
| 2 | UI 검수 반영 (공통 셸·입고예정·기준정보·업무 홈) | 입고예정 목록 시작 위치 344px → 218px(1280×609) |
| 3 | 뉴트럴 차콜 배색 적용 | 색상은 `globals.css` 공통 테마 변수로 관리 |
| 4 | 화면 검수용 예시 데이터 화면 추가 | `/dev/preview/plans` (메모리 데이터, DB 미저장) |
| 5 | 검증 | `tsc`·`next build` 통과, 자동 점검 35개 중 34개 통과(나머지 1개는 점검 기준값 문제) |
| 6 | 기준정보 구성 피드백 | `04. 피드백/01. 기준정보 구성 피드백.md` 작성 |

## 3. 주요 변경 내용

| 구분 | 변경 내용 |
| --- | --- |
| 왼쪽 메뉴 | 업무·기준정보·설정 그룹 접기·펼치기, 미구현 메뉴는 '준비 중인 메뉴'로 접음, 사용자 정보는 메뉴 아래 한 번만 표시 |
| 개발 단계 안내 | 메뉴·업무 홈에서 빼고 `/help`(개발 진행 안내)로 이동 |
| 업무 설명 | 화면 제목 옆 도움말(?)로 이동 |
| 입고예정 | 넓은 표 목록(`/plans`) → 전체 상세(`/plans/[id]`), 전체 폭 작성(`/plans/new`), 승인대기 연속 검토만 분할(`/plans/review`) |
| 입고예정 조회조건 | 처음부터 펼친 2줄 구성, 빠른 날짜 선택, 입력 중 조건과 적용 조건 구분, 접어도 적용 조건 요약, 상태별 건수와 결과 일치 |
| 목록 복귀 | 조건·상태·정렬·페이지·스크롤 위치·선택 대상 복원, 긴 표는 열 제목 고정 |
| 조직·화주사 | 화주사 목록 우선, 3PL 조직은 한 줄 요약과 별도 보기 |
| 품목·바코드·단위 | 편집 패널의 '전체 화면'(`/master/items/[id]`), '종료' 버튼을 누른 뒤 사유 입력 |
| 정책 | '적용 정책 확인'을 버튼으로 여는 패널로 이동 |
| 공통코드 | 코드 그룹 목록 + 선택한 그룹의 코드 표 |
| 업무 홈 | 처리할 건과 기한이 중요한 작업 우선, 미구현 작업함은 한 줄 안내 |
