# 상차등록(PDA)·상차확인서·운영 DB 반영 대화 요약

## 1. 요약

2026-11-05에는 정의서 ④ **차량별 상차등록**을 만들었다. 시작 전에 정할 네 가지를 질문으로 확인했고, Sol은 모두 추천안을 골랐다. PDA는 **같은 웹 앱의 모바일 화면(`/pda`)** 으로 만들고, 스캐너는 입력칸에 키보드처럼 입력하는 방식으로 한다. **상차확인서는 A4 인쇄 화면**으로 만들고, 지시수량을 넘으면 **입력할 때 경고만 하고 사유는 상차완료 때 한 번** 받는다. 범위는 **PDA와 웹 반영(화주사 ASN·3PL 현황)** 까지로 정했다.

구현한 기능은 다음과 같다. 상차담당은 PDA에서 상차지시서를 스캔하거나 무지시 상차로 시작하고, 품목 바코드를 스캔해 **추가로 실은 수량**을 쌓는다. 여러 작업자가 같은 차량을 동시에 실을 수 있고, 본인 입력만 정정·취소한다. **상차완료**(차량당 1회)를 하면 ASN과 상차지시서가 상차완료가 되고, **상차확인서(LD 번호·바코드)** 가 발행된다. 웹에서는 ASN 상세에 **상차 실적 카드**와 **상차확인서 인쇄**를 붙였고, ASN 없이 실은 **무지시 상차**는 목록에 별도 행으로 보인다.

이 PC의 `.env`가 운영 DB(Supabase)를 가리키고 있어서, 점검은 **로컬 임시 DB**에서 했다. 점검이 모두 통과한 뒤 Sol의 확인을 받아 **운영 DB에 마이그레이션을 반영**하고, `feat/loading` 브랜치에 커밋해 **push·`main` 병합**까지 마쳤다.

## 4. 만든 것

### 4-1. 화면 — PDA (화주사 상차담당)

| 화면 | 주소 | 구성 |
| --- | --- | --- |
| PDA 로그인 | `/pda/login` | PDA 역할(화주사 상차담당)이 있는 계정만. PDA 전용 계정이 Web으로 로그인하면 "PDA 화면(/pda)에서 로그인하세요" 안내 |
| PDA 첫 화면 | `/pda` | 상차지시서 바코드 칸(스캔 또는 LO- 번호 입력) · 작업 중인 차량(다른 작업자가 시작한 차량에 함께 들어감) · 상차할 차량(오늘·출고일 지난 지시서, "출고일 지남" 표시) · [무지시 상차](센터·차량번호) · 오늘 상차완료 |
| 상차 작업 | `/pda/load/[id]` | 차량번호·지시서·출고일·작업자 → 품목 바코드 스캔 → 미리 보기(품목·스캔 단위·지시·지금 합계) → 추가로 실은 수량 → [+ 싣기]. 품목별 지시/상차(왼쪽 띠 색: 일치·부족·초과·지시 외) · 내 입력([정정]·[취소]) · [상차완료] |
| 상차완료 확인 | (같은 화면) | 작업자·입력 건수·마지막 입력 시각, 품목 합계. 차이가 있으면 사유 선택(기타는 상세 필수). 작업자가 2명 이상이면 "아직 싣고 있지 않은지 확인" 안내 |
| 상차완료 뒤 | (같은 화면) | "상차완료" + 상차확인서 번호·바코드, 차이 사유, [처음으로]. 더는 입력할 수 없음 |

### 4-3. 상차 규칙

| 규칙 | 내용 | 근거 |
| --- | --- | --- |
| 입력 1건 | "추가로 실은 수량" 1행(작업자·단말·시각). 품목별 합계 = 취소되지 않은 입력 합 | C5 · D11 |
| 품목 차단 | 오늘 ASN에 없는 품목은 확인해도 차단. 다른 화주사 바코드는 "등록되지 않은 바코드" | C5 · D10 |
| 경고 | 지시수량 초과·지시 외 품목은 경고 후 [그래도 싣기]. 무지시 상차는 경고 없음 | C5, 결정 3 |
| 작업자 | 잠금 없음, 같은 차량에 함께 입력. 본인 입력만 정정·취소, 다른 작업자 입력은 5초마다 반영 | D11 |
| 상차완료 | 차량당 1회. 확인 화면에서 본 뒤 다른 입력이 들어오면 막고 다시 확인하게 함. 실은 품목이 없으면 불가. ASN 대비 차이(무지시는 항상)면 상차 차이 사유 필수 | C6 |
| 완료 결과 | 실적 상차완료, ASN 상차완료(= ASN 확정), 상차지시서 상차완료, ASN 이력(상차 시작·상차완료) | 4-2 · D13 |
| 무지시 상차 | ASN을 만들지 않음. 오늘 ASN이 없는 화주사는 실을 품목이 없어 시작 불가. 같은 차량을 다른 작업자가 시작했으면 함께 들어감 | D12 |
| 번호 | 상차 실적 = 상차확인서 `LD-YYYYMMDD-NNNN` (상차 시작일 기준) | ④ |

## 7. 결론

오늘은 **PDA 상차등록을 같은 웹 앱의 모바일 화면으로 만들었다.** 상차담당은 지시서 스캔 또는 무지시 상차로 시작해 품목별 추가수량을 쌓는다. 여러 사람이 함께 싣고, **상차완료 한 번으로 ASN 확정과 상차확인서 발행**까지 이어진다. 웹에서는 화주사·3PL 모두 **ASN 상세에서 상차 결과와 차이 사유를 보고 상차확인서를 인쇄**한다. 점검(서버 80건·브라우저 27건)을 모두 통과한 뒤 **운영 DB 반영, 커밋, push, `main` 병합**까지 마쳤다. 다음 대화에서는 **상차등록 화면 검수**를 한 뒤 **입고검수(PDA)** 로 넘어간다.
