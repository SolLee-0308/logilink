## 0. 한눈에 보기

## 1. 커밋과 정의서 v2.1 확정

- **커밋:** Sol 요청으로 feat/1119-load-diff-line에 지금까지의 작업을 커밋했다(f4c6079). 들어간 것은 상차 차이 사유 품목별 선택, 입고검수 참고 표시, 품목 등록 화면 화주사 비우기, 정의서 v2.0 초안, 대화 기록 26·27이다.
- **O6 확정:** O6는 상차 차이 사유 신규 코드 L06(화주사 추가 출고 요청)과 L07(ASN 수량·품목 입력 오류)의 이름과 적용 구분이다. Sol이 **안대로 확정**했다.
- **v2.1 작성:** 파일 삭제 금지·버전 올리기 규칙에 따라 v2.0을 고치지 않고 **v2.1 새 파일**을 만들었다. 바뀐 내용은 다음과 같다.
  - 머리말을 v2.1(확정)로 바꿨다.
  - 변경 이력에 v2.1 줄을 추가했다.
  - L06·L07 표기를 "신규(안)"에서 "신규(v2.0)"으로 바꿨다.
  - O6를 해소 표시했다.
  - 이 밖의 내용은 v2.0과 같다.
- **병합:** feat/1119-load-diff-line을 main에 병합했다(e00ba68). 품목 입수·BOX 확인 창(6687598)도 이때 함께 main에 들어갔다. 타입 검사와 단위 시험 95건이 모두 통과했다.

## 2. 운영 DB 맞춤

Sol은 "운영 DB만 마이그레이션하고, 기존 데이터는 지우고 현재 개발 DB 기준으로 맞춰 달라"고 했다. 작업 중에 "먼저 메인 푸시부터"라고 해서 push를 먼저 했다.

| 순서 | 작업 | 결과 |
| --- | --- | --- |
| 1 | main push | a753e69 → e00ba68 |
| 2 | 기존 운영 데이터 백업 | `C:\Users\solle\work\logiLink-backup\운영DB_백업_2026-11-20_마이그레이션전.json` (107KB, 저장소 밖) |
| 3 | `prisma migrate deploy` | 5개 적용: 20261114 arrival·arrival_backfill·rcv_void_check, 20261117 item_inner_qty, 20261119 load_line_diff_reason |
| 4 | 데이터 교체 | 표 39개를 비우고(truncate) 시험 DB 데이터를 넣은 뒤 일련번호 35개를 맞췄다. 한 트랜잭션으로 처리했다 |
| 5 | 검증 | 표별 건수가 시험 DB와 같고, 참조 제약 61개에 불일치가 없다 |

- **처리 중 문제:** 첫 실행은 센터↔사용자처럼 표끼리 서로 참조하는 구조 때문에 넣는 순서를 정하지 못하고 멈췄다. 운영 DB는 바뀌지 않았다.
- **해결:** 트랜잭션 안에서만 `session_replication_role = replica`로 참조 검사를 잠시 끄고 넣었다. 그 뒤 참조 제약을 모두 따로 점검했다.
- **영향:** 기존 운영 계정 13개가 지워졌다. 운영에서도 시험 DB 계정 26개를 쓰며, 비밀번호도 시험 DB와 같다.

## 4. 시연 대시보드 열기

- **결정:** Sol이 "시연 대시보드 준비 중 풀어줘"라고 했다. 이로써 11-13에 시연 사이트에서 대시보드를 막았던 결정을 거뒀다.
- **수정:** `src/lib/demo.ts`의 `dashboardReady`를 `() => true`로 바꿨다. 다시 막으려면 `() => !isDemoSite()`로 돌리면 된다.
- **반영:** 브랜치 feat/1120-demo-dashboard에서 커밋한 뒤 main에 fast-forward했다(6783e55). push 후 deploy 512d880으로 갱신했고 Vercel 배포가 성공했다.
- **화면에서 바뀐 점:** 웹 사이드바의 대시보드 메뉴가 열리고, 웹 로그인 후 첫 화면이 대시보드가 된다. PDA 대시보드 탭도 열린다.
- **확인 범위:** 시연 사이트에 직접 로그인해 보지는 않았다. 로그인하면 시연 DB에 기록이 남기 때문이다.

## 6. 결론

정의서는 v2.1로 확정됐고, 코드는 main에 병합·push됐다. 운영·시연·시험 DB는 구조와 데이터가 모두 같고, 시연 사이트는 대시보드까지 열린 최신 상태다. 남은 일은 **선생님께 새 계정을 알리고 시나리오 문서를 고치는 것**이다.
